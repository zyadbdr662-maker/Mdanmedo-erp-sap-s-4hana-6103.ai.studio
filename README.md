# MeDo ERP SaaS & Enterprise Platform (v4.2)

 نظام محاسبي وإداري متكامل (ERP) مصمم خصيصاً للشركات والمؤسسات التجارية، مدعوم ببنية تحتية سحابية متقدمة لإدارة الاشتراكات والتراخيص (SaaS).

---

## 🏗️ هيكلية النظام (System Architecture)

يعتمد نظام **MeDo ERP** على هيكلية برمجية حديثة ومتكاملة مقسمة إلى الوحدات التالية:
1. **الوحدات المحاسبية والمالية**: دليل الحسابات، قيود اليومية، دفتر الأستاذ، ميزان المراجعة، وقائمة الدخل.
2. **إدارة المخزون والمستودعات**: مراقبة الأصناف، الحركات المخزنية، والتنبيهات.
3. **المبيعات والمشتريات**: فواتير البيع والشراء، المرتجعات، وحسابات العملاء والموردين.
4. **الموارد البشرية والشؤون الإدارية**: إدارة الموظفين، الحضور والانصراف، ورواتب الكادر.
5. **المنصة السحابية وإدارة التراخيص (SaaS Platform)**: خاصة بإدارة المشتركين، إصدار الأرقام التسلسلية، ومراقبة الجلسات.

## 🛡️ سياسة التحكم بالصلاحيات (RBAC)

- **المستخدم العادي (`USER`)**:
  - يستطيع إنجاز كافة العمليات المحاسبية والمخزنية والإدارية المعتمدة.
  - لا يمكنه رؤية أو الوصول إلى وحدة إدارة المنصة السحابية (SaaS).
- **مدير النظام (`ADMIN` / `SUPER_ADMIN`)**:
  - يمتلك كافة صلاحيات النظام بالإضافة إلى التحكم الكامل في وحدة إدارة المنصة السحابية والتراخيص والروابط الفريدة.
